# فرصة

منصة شخصية تعمل على جهازك أو على استضافة مجانية: تجمع الوظائف من القنوات والمواقع التي تتابعها، تقيّم توافق كل فرصة مع ملفك، تجهّز رسالة التقديم، وترسلها من بريدك بعد موافقتك.

## ماذا تفعل

| الخطوة | التفاصيل |
| --- | --- |
| الجمع | قنوات تيليجرام العامة، خلاصات RSS، صفحات توظيف الشركات والجهات الحكومية، وتنبيهات البريد (لينكدإن، جدارات، بيت). تلقائياً كل ساعة أو بزر «اجمع الآن» |
| منع التكرار | بصمة لكل وظيفة من الرابط (بعد حذف معاملات التتبع) أو من النص |
| التحليل | تقييم سريع مجاني بمطابقة المهارات والمسمى والمدينة والخبرة، وتحليل عميق اختياري بنموذج لغوي |
| رسالة التقديم | بالعربية أو الإنجليزية، من ملفك وسيرتك، قابلة للتعديل قبل الإرسال |
| الإرسال | عبر SMTP من بريدك مع إرفاق السيرة PDF. لا يُرسل أي شيء إلا بضغطك «أرسل التقديم» |

## النشر على الإنترنت مجاناً

اتبع [DEPLOY.md](DEPLOY.md): Render للمنصة، وNeon لقاعدة البيانات، وGitHub Actions للجمع كل ساعة، وGmail Apps Script للإرسال. عند ضبط `APP_PASSWORD` تُقفل المنصة كلها خلف كلمة مرور.

## التشغيل السريع (Docker)

```bash
cp .env.example .env      # عدّل القيم
docker compose up -d --build
```

افتح http://localhost:8000 (الواجهة والخلفية في حاوية واحدة) ثم:

1. **ملفي**: أدخل مهاراتك والوظائف المستهدفة وارفع سيرتك PDF.
2. **المصادر**: أضف قنواتك ومواقعك.
3. **الفرص**: اضغط «اجمع الآن».

البيانات تُحفظ في مجلد `data/` (قاعدة SQLite، والسيرة الذاتية داخلها).

## التشغيل بدون Docker

```bash
# الخلفية
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# الواجهة (نافذة أخرى)
cd frontend
npm install
npm run dev
```

## إعداد المصادر

| المصدر | كيف تضيفه |
| --- | --- |
| قناة تيليجرام | النوع «قناة تيليجرام» واسمها مثل `@channel`. يجب أن تكون عامة |
| موقع توظيف | النوع «خلاصة RSS» إن كان الموقع يوفرها |
| صفحة توظيف شركة أو جهة | النوع «صفحة وظائف». تعمل مع الصفحات التي تنشر بيانات `JobPosting` المنظمة (أغلب أنظمة التوظيف الحديثة) |
| لينكدإن | فعّل «تنبيهات الوظائف» في حسابك، ثم أضف مصدر «تنبيهات البريد» بالمرسل `jobalerts-noreply@linkedin.com` |
| جدارات وبيت وغيرها | نفس طريقة لينكدإن: فعّل التنبيهات وأضف عنوان المرسل الذي يصلك منه التنبيه |
| وظيفة منفردة | «إضافة وظيفة» من الرابط أو بلصق نص الإعلان |

لماذا لا تُسحب لينكدإن مباشرة؟ شروطها تمنع الجمع الآلي وقد توقف الحساب. تنبيهات البريد طريقة نظامية وتصل بنفس الوظائف.

استخدم «اقبل فقط ما يحتوي» لتصفية القنوات العامة، مثل: `مطور، مهندس، developer، engineer`.

## البريد (Gmail)

1. فعّل التحقق بخطوتين في حساب Google.
2. أنشئ «كلمة مرور التطبيقات» من إعدادات الأمان.
3. ضعها في `SMTP_PASSWORD` (للإرسال) و`IMAP_PASSWORD` (لقراءة التنبيهات)، واسم البريد في `SMTP_USER` و`IMAP_USER`.

## التحليل العميق (اختياري)

بدونه تعمل المنصة بالتقييم السريع والقوالب الجاهزة. لتفعيله اختر مزوداً في `.env`:

```env
# سحابي
LLM_PROVIDER=anthropic   # أو openai
LLM_MODEL=<اسم النموذج>
LLM_API_KEY=<المفتاح>

# محلي بالكامل بدون إرسال بياناتك لأي جهة
LLM_PROVIDER=ollama
LLM_MODEL=qwen2.5:14b
LLM_BASE_URL=http://host.docker.internal:11434
```

التحليل العميق يعمل عند ضغطك «حلّل بعمق» في صفحة الوظيفة فقط، حتى لا تُستهلك تكلفة على كل إعلان.

## الهيكل

```
backend/
  app/collectors/   المجمّعات: telegram, rss, webpage, imap
  app/analysis/     التقييم السريع، طبقة النماذج، كتابة الرسائل
  app/routers/      واجهة API
  app/services.py   الجمع والحفظ والتقديم
  tests/            اختبارات pytest
frontend/           واجهة Next.js عربية (RTL)
```

توثيق API التفاعلي: http://localhost:8000/docs

## الاختبارات

```bash
cd backend
pip install -r requirements-dev.txt && playwright install chromium

pytest -q                                      # 30 اختبار وحدات وأمان
python tests/integration/run_integration.py   # تكامل على خادم حي مع مصادر وبريد محاكاة
python tests/integration/load_test.py         # الحمل والتزامن (5000 وظيفة)
cd .. && python e2e/run_e2e.py                # رحلة المستخدم كاملة عبر المتصفح
```

## الأمان

- الخدمتان مربوطتان بـ `127.0.0.1` فقط؛ لا تنشرها على خادم عام بدون مصادقة.
- كل طلب تعديل يحتاج ترويسة `X-Forsa-Client` (حماية من المواقع الأخرى المفتوحة في متصفحك).
- الجلب يرفض العناوين الداخلية ويحد حجم الصفحة بـ 5 ميجابايت.
- لا يُرسل أي تقديم إلا بضغطك «أرسل التقديم»، ولا يُرسل نفس التقديم مرتين.
